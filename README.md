# Custom Python AI Agent Harness

## Overview

This repository provides a **self‑contained autonomous AI coding agent** that can be run locally without any external orchestration services. The agent is designed to:
- **Understand user instructions** and translate them into concrete actions.
- **Interact safely with the host filesystem** using a minimal, sandboxed toolset (listing files, reading/writing files, persisting short notes).
- **Leverage an LLM backend** (OpenAI API or a local Ollama model) through a thin, OpenAI‑compatible client wrapper.
- **Maintain a persistent memory store** (Markdown) that survives across multiple runs, allowing the agent to remember past interactions, important constants, or configuration data.
- **Operate entirely within a sandboxed workspace**, making it suitable for educational purposes, prototyping, or secure experimentation.

### Core Concepts

- **Agentic Loop** – The `Agent` class (in `src/agent.py`) implements a simple reasoning loop: it receives a user prompt, decides whether to call a tool, executes the tool, and finally produces a response. This mirrors the ReAct pattern used in many autonomous agents.
- **Tool Suite** – Implemented in `src/tools.py`, the tool suite provides safe file‑system operations limited to the workspace directory, preventing accidental access to the broader host system.
- **Memory System** – `src/memory.py` reads and writes a Markdown file (`memory.md` by default). The format is intentionally human‑readable so developers can inspect or edit it directly.
- **Configuration** – All paths, model selection, and runtime flags are centralized in `src/config.py`, making the agent easy to configure via environment variables or a `.env` file.
- **LLM Client Abstraction** – `src/llm_client.py` abstracts away the details of talking to OpenAI or Ollama, exposing a single `ChatCompletion`‑style interface that the agent consumes.
